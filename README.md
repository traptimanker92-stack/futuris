# Futuris 🚀
> **AI-Powered Career & Future Simulator** — An advanced career path ecosystem built for students, career switchers, and higher education aspirants.

---

## 🌟 About
**Futuris** is an all-in-one AI-powered career guidance and professional growth web application. Inspired by advanced hackathon problem statements, it moves beyond static career quizzes to simulate realistic career trajectories complete with year-by-year milestones, skill gaps, dynamic timelines, interactive task trackers, custom focus tools, a creative ATS resume builder, and live interview prep[cite: 1].

---

## ✨ Key Features & Modules

* **3D Cinematic Portal Transition:** Features an immersive post-login transition (inspired by Lusion-style space/tunnel effects) using Three.js and Framer Motion before landing on the dashboard[cite: 2].
* **Dynamic Career Simulation:** Instantly queries live data patterns and market skill demands for *any* career path entered by the user.
* **Tailored Onboarding:** Dual-mode setup customized for students (school/college), working professionals, and higher studies aspirants (with zero technical tracking labels).
* **Animated & Interactive Roadmaps:** Smooth SVG/node-based timelines with expandable milestones and real-time progress tracking[cite: 1].
* **AI Mock Interview Copilot:** Generates personalized technical and behavioral interview questions based on the user's specific skill gaps.
* **Gamified XP & Streak System:** Earn experience points, level up badges, and track daily progress as tasks and study sessions are completed.
* **Customizable "Regain" Focus App:** Built-in productivity suite with adjustable timer intervals, focus streaks, and distraction logs.
* **Creative Resume & Portfolio Builder:** Modern ATS-compliant CV layout featuring profile photo uploads, animated progress meters, skill tag pills, and one-click PDF export.
* **Interactive Task Manager:** Checklists ("Add Task", "Complete Task") updating dynamic readiness scores.
* **Dual Theme Engine:** Seamlessly toggle between pristine Light Mode and deep Dark Mode across all components.

## 🛠️ Tech Stack
* **Frontend:** React.js / Next.js, Tailwind CSS
* **Animations:** Framer Motion, Three.js / WebGL[cite: 2]
* **State Management:** Local Storage / React Hooks
